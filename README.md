# PixelBG: пиксельные фоны локаций для браузерной игры

12 локаций, у каждой две версии: **день** и **вечер/ночь**. Фон рисуется кодом на canvas, подстраивается под любой экран (монитор, ультравайд, телефон вертикально и горизонтально) и сам выбирает день или ночь по времени игрока. Двигается только атмосфера: облака, звёзды, дым, волны, огоньки, птицы. Постройки, горы и деревья стоят на месте.

Это JavaScript, а не Python. Python нужен только мне для сборки и проверки (папка `tools`), в игре его нет. Внешних библиотек и картинок тоже нет: весь пакет это один файл `pixelbg.all.js` (около 290 КБ, примерно 60 КБ после gzip на сервере).

## Быстрый старт

```html
<div id="bg" style="position:fixed; inset:0"></div>
<script src="pixelbg.all.js"></script>
<script>
  const bg = PixelBG.mount('#bg', { location: 'forest' });
</script>
```

Всё. День или ночь выберется по часам компьютера игрока. Поверх `#bg` кладите интерфейс игры обычным образом.

Посмотреть все локации можно в `demo.html` (нужен `pixelbg.all.js` рядом) или `demo.single.html` (один файл, открывается двойным кликом). В демо есть список локаций, кнопки «Авто / День / Ночь», ползунок часа и примерки форматов экрана.

## Как выбирается день или ночь

По умолчанию **день с 7:00 до 19:00, остальное время ночь**. Выбор делается в момент входа в локацию (`mount` или `setLocation`). Если игрок остался в локации и наступил вечер, фон сам плавно перейдёт в ночь (проверка раз в 15 секунд). Это можно выключить: `followClock: false`.

Что можно настроить:

```js
// свои границы дня
PixelBG.mount('#bg', { location: 'taiga', dayStart: 8, nightStart: 21 });

// в игре своё время суток (число от 0 до 24, например 21.5 = 21:30)
PixelBG.mount('#bg', { location: 'taiga', getHour: () => game.clock.hour });

// принудительно: 'day' | 'night' | 'auto' (по умолчанию)
PixelBG.mount('#bg', { location: 'taiga', time: 'night' });
```

## Управление фоном

```js
const bg = PixelBG.mount('#bg', { location: 'desert' });

bg.setLocation('sea');               // смена локации с плавным переходом (1,2 с)
bg.setLocation('sea', { fade: false }); // мгновенно
bg.setTime('day');                   // 'auto' | 'day' | 'night'
bg.setHour(22);                      // подсказать время; setHour(null) вернёт часы компьютера или getHour
bg.pause(); bg.resume();             // например, пока открыто полноэкранное меню
bg.resize();                         // сам вызывается при смене размера контейнера
bg.destroy();                        // убрать фон со страницы
bg.variant;  bg.location;            // сейчас 'day' или 'night', и какая локация
```

Все опции `mount`:

| опция | по умолчанию | зачем |
|---|---|---|
| `location` | нет | id локации |
| `time` | `'auto'` | `'auto'`, `'day'` или `'night'` |
| `getHour` | нет | функция внутриигровых часов, 0..24 |
| `dayStart`, `nightStart` | 7 и 19 | границы дня |
| `followClock` | `true` | сам перейти день→ночь, пока игрок в локации |
| `fade` | 1200 | длительность перехода в мс, `0` без перехода |
| `fps` | 10 | кадров в секунду (пиксель-арт и так живёт на 10) |
| `reducedMotion` | `'respect'` | если в системе включено «уменьшить движение», показывается один неподвижный кадр; `'ignore'` отключает это |
| `onChange` | нет | `({location, variant}) => …`, вызывается при каждой сборке сцены |

## Как фон подстраивается под экран

Фон рисуется в маленьком холсте высотой около 192 пикселей (а у телефона в вертикали, например, 90×195), потом увеличивается в **целое** число раз, поэтому пиксели везде квадратные и чёткие. Земля и горизонт привязаны к низу экрана, небо растёт вместе с высотой. Главный объект сцены стоит в центре, на широких экранах по бокам достраивается декор (деревья, дома, скалы, облака), так что пустых полос нет.

Проверено на пяти размерах: монитор 1920×1080, ультравайд 3440×1440, телефон вертикально (390×844), телефон горизонтально (844×390), планшет (820×1180).

Скорость (замеры в Chromium на облачном процессоре, на телефоне будет медленнее, но запас большой): кадр рисуется за 0.3–5.5 мс при бюджете 100 мс на кадр (10 кадров в секунду). Самые тяжёлые сцены: лес ночью и магический с гибридным городами ночью на ультравайде. Статичные слои строятся один раз при входе в локацию (в замерах до 45 мс, у большинства около 10 мс), дальше каждый кадр рисуются только движущиеся детали. На фоновых вкладках браузер сам останавливает анимацию.

## Если нужно поправить или добавить локацию

Исходники лежат в `src/`: `src/engine.js` и `src/scenes/<id>.js`. После правок выполните `cd src && python3 tools/build.py`, это пересоберёт `src/dist/pixelbg.all.js`, демо и zip. Каждая сцена это функция `PixelBG.register('id', env => ({ draw(ctx, f) {…} }))`. Шапка `src/engine.js` объясняет, что лежит в `env`, и есть набор помощников (`env.px`): градиенты, облака, звёзды, волны, дым, свечение, полярное сияние и т.д.

Правила, по которым сделаны все сцены: только целые пиксели без сглаживания, кадр это чистая функция номера кадра `f` (никакого случайного в `draw`), вся случайность только при сборке сцены и с фиксированным зерном, главный объект в пределах 34 пикселей от центра.
